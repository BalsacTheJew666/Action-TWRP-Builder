# XT2615-1 Nevada — authoritative GKI release ABI CRC comparison

## Why

Run **#40413637325** successfully compiled the four experimental AR9271 Atheros kernel modules and matched **30/30** imported CRCs measured from SHA256-verified saved stock `cfg80211.ko` and `mac80211.ko`. It reported another **136** imports matching a **candidate** `vmlinux.symvers` generated by the experimental kernel compilation. That is not evidence the Moto G Play 2026's *actual base kernel* exports the same CRCs.

## New provenance: exact kernel binary build, not merely source

The device's running Linux version is:

```
5.15.180-android13-8-00018-g9b2308ac0ad6-ab14563692
```

The GKI release tag `android13-5.15-2025-05_r14` in Google's official kernel/common repository pins commit `9b2308ac0ad616788fb57ba688aa07f0ff221355`, and its **release artifact URL** is:

```
https://ci.android.com/builds/submitted/14563692/kernel_aarch64/latest
```

See the public original release tag: https://android.googlesource.com/kernel/common/+/refs/tags/android13-5.15-2025-05_r14

The suffix `ab14563692` agrees with the official build ID **14563692**, giving a much more relevant candidate binary-export reference than a locally recompiled `vmlinux.symvers`.

Android's GKI artifact documentation lists **`vmlinux.symvers`** as a kernel artifact for mixed builds: https://source.android.com/docs/core/architecture/kernel/gki-android13-5_15-release-builds

## CI-only experiment

1. Fetch the precise previous successful four-module **NOT-INSTALLABLE** diagnostic artifact from GitHub Actions run #40413637325. Do not build, flash, patch, sign or install anything new.
2. Fetch **only** Google's exact build `14563692` `vmlinux.symvers` over HTTPS from `https://ci.android.com/builds/submitted/14563692/kernel_aarch64/latest/raw/vmlinux.symvers`, validating that it is a plausible symbol table (at least 1,000 exported `vmlinux` CRC entries) rather than an HTML login page.
3. Parse the experimental `.ko` ELF `__versions` imports and compare all against:
   - the 30 stock wireless export CRCs already verified from preserved actual stock `.ko` binaries,
   - the 67 internal Atheros module-to-module CRCs,
   - **the new official released GKI** `vmlinux.symvers` instead of the 136 experimental kernel CRC references.
4. Save JSON and text summaries. **Do not re-upload kernel modules, binaries, boot or recovery images.**

If Google's direct download link requires access, is expired, or returns a non-symvers response, the CI reports **comparison not completed**. It MUST NOT silently substitute the candidate compiler-generated `vmlinux.symvers` and MUST NOT claim verified core compatibility.

## Interpretation and next gate

A match for each of the 136 previously experimental-core imports against the authentic **official GKI build** would strongly support the base-kernel symbol-version hypothesis, but still would **not** prove on-device module-loading viability. The device may include Motorola/vendor modifications, KernelSU injection, CFI/LTO restrictions, module signature policy, and vendor module version metadata; firmware `htc_9271-1.4.0.fw`, physical USB OTG, and actual dongle enumeration need separate tests.

To finish, we will need a **read-only on-device report** of running GKI build identity, module security policies, `vermagic`/CFI settings, and existing stock module identity. Do not force `insmod`, alter CRC or `vermagic`, replace stock wireless modules, change the kernel or flash anything yet.

The GitHub Actions workflow is research-only, running in cloud CI. Current KernelSU, TWRP/OrangeFox, PBRP/SHRP and internal MediaTek Wi-Fi remain untouched.
